This sandbox connects directly to our real-time wholesale beverage order backend using Llama 3.3 via Groq and FastAPI streaming pipelines.

How to Start Your Interview Demo

  1. Look for the floating blue phone icon in the bottom-right corner of this webpage.
  2. Click the icon and grant microphone permissions if prompted by your browser.
  3. Speak directly to the agent to place, negotiate, or manage fruit juice wholesale volumes.
  4. Watch your local terminal logs to see live pipeline execution events streaming frame by frame.
